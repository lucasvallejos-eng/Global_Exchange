# Conversaciones con IA

Acá se documentan las conversaciones con asistentes de IA que se usaron para
construir el sistema, como pide el criterio CHIA de la guía de la cátedra.

## Convención de nombres

```
AAAA-MM-DD-tema-corto.md
```

## Qué va en cada archivo

- **Contexto**: qué problema se estaba resolviendo y por qué.
- **Qué se le pidió a la IA**: el pedido, en las palabras del equipo.
- **Qué respondió / qué se hizo**: los cambios concretos que salieron de ahí.
- **Qué se descartó y por qué**: tan importante como lo que se aceptó. Deja
  registro de que las sugerencias se revisaron en vez de aplicarse a ciegas.
- **Verificación**: cómo se comprobó que lo que se hizo funciona.
